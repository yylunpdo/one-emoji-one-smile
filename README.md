One emoji, one smile: this entry sends exactly one emoji — 🤗 (U+1F917 HUGGING FACE) — the one most likely to make a stranger smile. A hug plainly aims to warm a stranger: a smiling face with open hands, kind at first glance, universal across ages and backgrounds, chosen rather than the first smiley that comes to mind, and friendly without intimacy, sarcasm, or flirtation. `main.py` (Python standard library only) writes that single emoji, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
